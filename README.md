# nanoGPT

**A from-scratch implementation of Andrej Karpathy's [nanoGPT](https://github.com/karpathy/nanoGPT) along with the emphasis on intuitive understanding of language modeling**

---

## Overview

This repository will have following things covered:
1. Bigrams - a baseline for language models
2. Tokenization - character level to BPE
3. Simple GPT using tiny shakespeare dataset
4. Rebuilding GPT-2(124M) model using Fineweb-edu (10B sample) dataset
